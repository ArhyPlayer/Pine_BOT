# 🤖 Диалоговый бот с памятью

> 📸 **Демонстрация работы:** с примерами работы бота можно ознакомиться в директории [Screenshots](Screenshots).

Умный ассистент с долговременной памятью на базе Pinecone, Haystack и OpenAI. Работает в двух режимах:

- **Приватный чат** — персональный ассистент: запоминает всё, что вы пишете, анализирует загруженные документы (PDF, DOCX, PPTX и др.) через Docling и использует накопленный контекст для точных ответов.
- **Групповой чат** — командный помощник: слушает переписку команды, записывает сессии обсуждений, автоматически составляет резюме с выводами и отвечает на вопросы по всей истории чата через упоминание `@бот`.

## 🚀 Быстрый старт

### Шаг 1: Установка зависимостей
```bash
python -m venv .venv
source .venv/bin/activate  # macOS/Linux
# или .venv\Scripts\activate на Windows

pip install -r requirements.txt
```

### Шаг 2: Настройка .env
```bash
cp env-example .env
```

Откройте `.env` и заполните:
- `TELEGRAM_BOT_TOKEN` — получите у [@BotFather](https://t.me/botfather)
- `OPENAI_API_KEY` — ваш ключ OpenAI API
- `PINECONE_API_KEY` — ваш ключ Pinecone API
- `PINECONE_INDEX_NAME` — имя индекса (например, `dialog-bot`)
- `BOT_USERNAME` — username бота без `@` (опционально, определяется автоматически)

### Шаг 3: Создание индекса Pinecone (опционально)
Индекс создастся автоматически при первом запуске, или создайте вручную:
- Dimension: **1536**
- Metric: **cosine**
- Cloud: **AWS**
- Region: **us-east-1**

### Шаг 4: Запуск бота
```bash
python bot.py
```

### Шаг 5: Тестирование
Откройте вашего бота в Telegram и отправьте `/start`

**Готово! 🎉** Бот запущен и готов к работе!

## 🌟 Особенности

### Приватный чат
- **🧠 Долговременная память** — каждое сообщение сохраняется в Pinecone и используется в будущих ответах
- **📄 Анализ документов** — отправьте PDF, DOCX, PPTX или HTML — бот изучит содержимое и ответит на вопросы по нему
- **🎯 Единый контекст** — при ответе агент одновременно учитывает сообщения и загруженные документы
- **🔍 Семантический поиск** — находит релевантную информацию по смыслу, а не по ключевым словам
- **🚫 Защита от дубликатов** — проверяет косинусное сходство, обновляет похожие записи
- **📋 Авто-резюме** — после загрузки файла бот сразу даёт краткое описание содержимого
- **🗑️ Управление памятью** — просмотр сообщений и загруженных документов, полная очистка
- **🤖 Haystack-агент с инструментами** — при установленных зависимостях работает как агент с тулзами: факты о собаках, фото породы с описанием через OpenAI Vision

### Групповой чат
- **🎙 Запись сессий** — команды `/listen_start` / `/listen_stop` позволяют зафиксировать конкретный отрезок обсуждения
- **📊 Умное резюме** — после остановки записи нейросеть анализирует диалог: выделяет суть спора, фиксирует принятые решения, перечисляет задачи и ответственных
- **💾 Непрерывное индексирование** — все сообщения чата автоматически сохраняются в Pinecone через Haystack pipeline, даже без активной сессии
- **🔎 Ответы по контексту** — упоминание `@бот вопрос?` запускает семантический поиск по всей истории чата и возвращает ответ с указанием авторов и времени
- **🏢 Изоляция чатов** — данные каждого группового чата хранятся в отдельном Pinecone namespace (`group_{chat_id}`)

## 📱 Команды бота

### Приватный чат

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и краткое описание возможностей |
| `/help` | Справка: команды, форматы файлов, примеры |
| `/memory` | Загруженные документы и запомненные сообщения |
| `/clear` | Полностью очистить память (сообщения + документы) |
| `/forget [текст]` | Найти в памяти похожую информацию |

> 📄 **Для загрузки файла** просто отправьте его боту как вложение — никаких команд не нужно.

### Групповой чат

| Команда | Описание |
|---------|----------|
| `/listen_start` | Начать запись сессии диалога. Все последующие сообщения будут накапливаться в буфере |
| `/listen_stop` | Остановить запись. Нейросеть проанализирует накопленный диалог и пришлёт структурированный итог |
| `@бот вопрос?` | Задать боту вопрос. Бот найдёт релевантные сообщения в истории чата и ответит со ссылками на авторов |

> 💡 **Все сообщения группы** индексируются в Pinecone автоматически — даже когда запись сессии не активна. Это означает, что бот «помнит» всю переписку и может отвечать на вопросы по любому периоду обсуждения.

## 👥 Групповой чат — командный помощник

Бот может быть добавлен в рабочий Telegram-чат команды. В групповом режиме он выполняет три функции:

1. **Автоиндексирование** — каждое сообщение сохраняется в векторную базу через Haystack pipeline
2. **Запись сессий** — по команде фиксирует конкретный отрезок обсуждения и формирует итог
3. **Ответы на вопросы** — при упоминании выполняет семантический поиск по всей истории чата

### Настройка: включить получение всех сообщений

По умолчанию Telegram-боты получают только команды и упоминания в группах. Чтобы бот получал **все сообщения**, нужно один раз отключить Privacy Mode:

1. Откройте [@BotFather](https://t.me/botfather)
2. Отправьте `/mybots` → выберите вашего бота
3. Перейдите в **Bot Settings → Group Privacy**
4. Нажмите **Turn off**

После этого добавьте бота в нужную группу и назначьте его администратором (или просто участником).

### Как работает Haystack pipeline для группового чата

```
Сообщение участника группы
         │
         ▼
 GroupChatHandlers._on_group_message()
         │
    ┌────┴───────────────────────────┐
    │                                │
    ▼                                ▼
Активна запись?              Есть упоминание @бот?
(если да — в буфер)          (если да — поиск + ответ)
    │                                │
    └────────────┬───────────────────┘
                 │ всегда
                 ▼
   [Фоновый поток]
   Indexing Pipeline:
   OpenAIDocumentEmbedder
         │  эмбеддинг (text-embedding-3-small)
         ▼
   DocumentWriter
         │
         ▼
   PineconeDocumentStore
   namespace: group_{chat_id}

/listen_stop
         │
         ▼
   [Фоновый поток]
   OpenAIChatGenerator (GPT)
         │  анализ буфера диалога
         ▼
   Структурированное резюме → чат

@бот вопрос?
         │
         ▼
   Querying Pipeline:
   OpenAITextEmbedder → PineconeEmbeddingRetriever
         │  top-10 релевантных сообщений
         ▼
   OpenAIChatGenerator (GPT)
         │  ответ с указанием авторов
         ▼
   Ответ в чат
```

### Изоляция данных между чатами

Каждый групповой чат хранит данные в **отдельном Pinecone namespace** (`group_{chat_id}`). Это означает:
- Данные чатов не перемешиваются между собой
- При упоминании бота он ищет только по истории **текущего** чата
- Разные команды в разных чатах полностью изолированы

## 🤖 Haystack-агент

Бот интегрирован с фреймворком [Haystack](https://haystack.deepset.ai/). При наличии зависимостей каждое сообщение обрабатывает полноценный агент с инструментами (tools), а не просто запрос к OpenAI.

### Как проверить, что агент активен

При запуске `bot.py` в консоли должна появиться строка:
```
✓ Haystack-агент инициализирован
```

Если написано `⚠️ haystack-ai не установлен` — установите зависимости:
```bash
pip install -r requirements.txt
```

### Как работает агент

```
Сообщение пользователя
        │
        ▼
 MemoryManager.retrieve()          ← семантический поиск по Pinecone
        │ контекст (факты)
        ▼
  HaystackAgent.reply()
        │
        ▼
 OpenAIChatGenerator (o4-mini)     ← LLM с системным промптом + контекстом
        │ нужен инструмент?
    ┌───┴───────────────────┐
    │                       │
    ▼                       ▼
dog_fact              dog_image_describe
(внешний API)         (внешний API + Vision)
    │                       │
    └───────┬───────────────┘
            │ результат инструмента
            ▼
   Финальный ответ пользователю
        │
        ▼
 MemoryManager.extract_facts()     ← извлечение фактов
 MemoryManager.save()              ← сохранение в Pinecone
```


### Как добавить новый инструмент

1. Создайте Haystack-компонент в `agent/tools.py`:

```python
@component
class MyTool:
    """Описание для LLM: когда использовать этот инструмент."""

    @component.output_types(result=str)
    def run(self, **kwargs) -> dict:
        # логика инструмента
        return {"result": "ответ"}
```

2. Зарегистрируйте его в `agent/assistant.py` в методе `_build()`:

```python
my_tool = ComponentTool(
    component=MyTool(),
    name="my_tool",
    description="Краткое описание для LLM: когда вызывать.",
)
return Agent(
    ...
    tools=[dog_fact_tool, dog_image_tool, my_tool],
    ...
)
```

3. Добавьте упоминание инструмента в `_SYSTEM_PROMPT` класса `HaystackAgent`.

## 📄 Обработка документов (Docling)

Бот умеет принимать файлы прямо в Telegram и сохранять их содержимое в Pinecone для дальнейшего анализа.

### Поддерживаемые форматы

| Расширение | Описание |
|------------|----------|
| `.pdf`     | PDF-документы с текстом и таблицами |
| `.docx`    | Документы Microsoft Word |
| `.pptx`    | Презентации PowerPoint |
| `.html`, `.htm` | HTML-страницы |
| `.md`      | Markdown-файлы |
| `.adoc`, `.asciidoc` | AsciiDoc-файлы |

### Как загрузить файл

Просто отправьте файл боту как вложение — никаких команд не нужно:

```
1. Откройте диалог с ботом в Telegram
2. Нажмите значок скрепки / прикрепить файл
3. Выберите документ на устройстве
4. Отправьте
```

Бот ответит немедленно, а обработка идёт в фоне:

```
📄 Файл получен. Запускаю анализ и сохранение.
   Это может занять немного времени…

✅ Готово. Я изучил этот файл, теперь можем его обсудить.
📋 <Одно предложение — краткое резюме содержимого>
```

### Что происходит под капотом

```
Файл из Telegram
       │
       ▼
  Docling.convert()          ← разбор PDF/DOCX/HTML, таблиц, заголовков
       │ DocumentChunker
       ▼
  Чанки с метаданными        ← filename, page_no, headings
       │
       ▼
  PineconeManager.upsert()   ← каждый чанк → эмбеддинг → Pinecone
       │
       ▼
  MemoryManager.save_doc_index()  ← «паспорт» документа (имя, кол-во чанков)
       │
       ▼
  OpenAI (резюме)            ← бот отправляет пользователю 1 предложение
```

### Вопросы по документу после загрузки

После загрузки любого файла просто задавайте вопросы в свободной форме:

```
👤 Кратко суммируй основные тезисы
👤 Что написано про раздел 3?
👤 Есть ли в документе упоминание [ключевого слова]?

```

Агент автоматически ищет релевантные фрагменты в Pinecone и формирует ответ.


### Повторная загрузка файла

Если вы загрузите файл с тем же именем ещё раз, запись в индексе обновится (старые чанки не накапливаются).

### Алгоритм работы

**Текстовое сообщение:**

1. Сообщение пользователя поступает в `BotHandlers._on_text`
2. `MemoryManager.retrieve()` ищет семантически близкие фрагменты в Pinecone (сообщения + документы)
3. Контекст + история сессии + сообщение передаются в `HaystackAgent.reply()`
4. Агент при необходимости вызывает инструменты (dog_fact, dog_image_describe)
5. Ответ отправляется пользователю
6. Сообщение пользователя сохраняется в Pinecone (`type="message"`)

**Загрузка файла:**

1. Файл поступает в `BotHandlers._on_document`, бот немедленно отвечает «получен»
2. В фоновом потоке запускается `DoclingIngestionPipeline.process()`
3. Docling разбирает документ, `DocumentChunker` делит на фрагменты
4. Каждый чанк сохраняется в Pinecone (`type="doc_chunk"`) с метаданными
5. Сохраняется «паспорт» документа (`type="doc_index"`)
6. `DoclingIngestionPipeline.summarize()` генерирует однострочное резюме
7. Бот отправляет пользователю «Готово» + резюме

### Система памяти

Pinecone хранит данные в **изолированных namespace'ах**:

| Namespace | Кто использует | Описание |
|-----------|---------------|----------|
| `user_{user_id}` | Приватный чат | Сообщения и документы конкретного пользователя |
| `group_{chat_id}` | Групповой чат | Переписка конкретной группы (Haystack pipeline) |

**Типы записей в приватном чате:**

| Тип | Что хранит | Кто создаёт |
|-----|-----------|-------------|
| `message` | Сырой текст сообщения пользователя | `BotHandlers._on_text` |
| `doc_chunk` | Фрагмент документа + метаданные (filename, page_no, headings) | `DoclingIngestionPipeline.process` |
| `doc_index` | «Паспорт» документа (имя файла, количество фрагментов) | `DoclingIngestionPipeline.process` |

**Групповой чат** хранит Haystack `Document` объекты с метаданными: `chat_id`, `user_id`, `username`, `timestamp`, `datetime`.

**Общие особенности:**
- Все записи — эмбеддинги 1536 измерений (`text-embedding-3-small`)
- Поиск по семантическому сходству (cosine similarity)
- Защита от дубликатов для сообщений приватного чата (cosine ≥ 0.80 → обновление)
- При ответе в приватном чате `MemoryManager.format_for_context()` разделяет контекст на два блока: «Из загруженных документов» и «Прошлые сообщения пользователя»

**Что игнорируется:**
- Общие вопросы без информации
- Команды боту
- Благодарности и приветствия

**Пример:**
```
Вход: "Я люблю программировать на Python и работаю в IT"
Извлечено: 
  - Увлекается программированием на Python
  - Работает в IT сфере
```

### Настройки дубликатов

В `memory/store.py` можно настроить пороги сходства:

```python
SIMILARITY_THRESHOLD_HIGH = 0.80  # Выше - дубликат (обновляем)
SIMILARITY_THRESHOLD_LOW = 0.75   # Ниже - новая информация (сохраняем)
```

**Статусы сходства:**
- **score ≥ 0.85** → "duplicate" - обновляет существующий факт
- **0.7 ≤ score < 0.85** → "similar" - сохраняет как новый факт
- **score < 0.7** → "new" - явно новая информация

### Специальные запросы

При определенных запросах бот возвращает **все факты без фильтрации** по релевантности:

**Триггерные фразы:**
- "все предпочтения"
- "мои предпочтения"
- "напомни мне"
- "расскажи о мне"
- "что ты знаешь обо мне"

Это полезно для команды `/memory` и запросов типа "напомни все, что знаешь".

## 🔧 Настройка и оптимизация

### Изменение модели чата

Отредактируйте параметр `CHAT_MODEL` в `.env`:
```env
CHAT_MODEL=o4-mini-2025-04-16  # Или другая модель
```

### Изменение модели эмбеддингов

При изменении модели эмбеддингов нужно также обновить размерность в индексе:
```env
EMBEDDING_MODEL=text-embedding-3-large  # Dimension: 3072
```

### Настройка параметров памяти

В файле `handlers/telegram.py` можно изменить:
- `top_k` — количество фактов для извлечения (по умолчанию 10)

В файле `agent/assistant.py` в `generation_kwargs`:
- `max_completion_tokens` — максимальная длина ответа агента (по умолчанию 1000)

В файле `memory/store.py` настройки порогов дубликатов:
- `SIMILARITY_THRESHOLD_HIGH = 0.80` — выше считается дубликатом (обновляется)
- `SIMILARITY_THRESHOLD_LOW = 0.75` — ниже считается новой информацией

**Примечание:** Модель `o4-mini-2025-04-16` не поддерживает настройку `temperature` - используется только значение по умолчанию.

## 🐛 Решение проблем

### Ошибка "Невозможно разрешить импорт"
```bash
# Убедитесь, что виртуальное окружение активировано
source .venv/bin/activate  # macOS/Linux
.venv\Scripts\activate     # Windows

# Переустановите зависимости
pip install -r requirements.txt
```

### Ошибка подключения к Pinecone
- Проверьте правильность `PINECONE_API_KEY`
- Убедитесь, что индекс создан с правильной размерностью (1536)
- Проверьте интернет-соединение

### Ошибка OpenAI API
- Проверьте наличие средств на аккаунте OpenAI
- Убедитесь в правильности `OPENAI_API_KEY`
- Если используете ProxyAPI, проверьте `OPENAI_BASE_URL`

### Бот не отвечает в Telegram
- Убедитесь, что бот запущен (`python bot.py`)
- Проверьте правильность `TELEGRAM_BOT_TOKEN`
- Убедитесь, что бот не заблокирован в Telegram

### Загрузка файлов не работает
Если в консоли при запуске:
```
⚠️ docling не установлен — загрузка файлов недоступна
```
Установите пакет:
```bash
pip install docling
```
Установка занимает несколько минут — Docling подтягивает ML-зависимости для анализа документов.

### Файл загружается, но бот отвечает «Формат не поддерживается»
Убедитесь, что расширение файла входит в список поддерживаемых:
`.pdf`, `.docx`, `.pptx`, `.html`, `.htm`, `.md`, `.adoc`, `.asciidoc`

### Обработка файла зависает или занимает очень долго
Docling выполняет глубокий ML-анализ документа (OCR, таблицы, разметка). Для больших PDF (50+ страниц) это нормально. Бот продолжает отвечать на другие сообщения — обработка идёт в фоне.

### Бот не реагирует на сообщения в группе (только на команды)
Включите Privacy Mode Off в настройках бота:
1. Откройте [@BotFather](https://t.me/botfather)
2. `/mybots` → выберите бота → **Bot Settings → Group Privacy → Turn off**

### Бот не реагирует на упоминание `@бот вопрос?`
- Убедитесь, что `BOT_USERNAME` задан в `.env` или что при старте в логах появилось `Username бота: @имя_бота`
- Проверьте, что упоминание является Telegram entity типа `mention` (синяя ссылка), а не просто текстом `@имя_бота`

### Групповые функции недоступны (сообщение при старте)
Если в консоли: `⚠️ pinecone-haystack не установлен — функции групповых чатов недоступны`, выполните:
```bash
pip install pinecone-haystack
```

### `/listen_stop` — «Запись не была активна»
Команды `/listen_start` и `/listen_stop` привязаны к конкретному чату. Убедитесь, что обе команды отправляются **в одной и той же группе**.
